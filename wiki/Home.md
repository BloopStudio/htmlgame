# Bienvenue sur le wiki de CodeQuest 🕹️

**CodeQuest** est un jeu web gratuit et open source pour apprendre à coder en
**HTML**, **CSS**, **JavaScript** et **PHP**, directement dans le navigateur.

- 🎮 **Jouer en ligne :** https://bloopstudio.github.io/htmlgame/
- 💻 **Code source :** https://github.com/BloopStudio/htmlgame

## Comment jouer

1. Choisis un défi dans le parcours **HTML** (le premier débloqué).
2. Écris ton code dans l'éditeur.
3. Clique sur **▶ Vérifier** : le jeu teste ton code en direct.
4. Une fois le défi réussi, tu gagnes de l'XP et débloques le suivant.
5. Termine tous les défis d'un parcours pour débloquer le parcours suivant
   (HTML → CSS → JavaScript → PHP).

Ta progression est sauvegardée automatiquement dans ton navigateur : tu peux
fermer l'onglet et reprendre plus tard là où tu t'étais arrêté·e.

## Pourquoi ce projet ?

CodeQuest est né de l'envie d'avoir un support d'apprentissage simple,
gratuit, sans inscription ni compte, qui fonctionne directement depuis une
page GitHub Pages. Le code est entièrement ouvert : n'hésite pas à
[contribuer](Contribuer) !
