# Contribuer

CodeQuest est open source : toute contribution est la bienvenue, que ce soit
un nouveau défi, une correction de bug, ou une amélioration de
l'interface.

Le guide complet se trouve dans le fichier
[`CONTRIBUTING.md`](https://github.com/BloopStudio/htmlgame/blob/main/CONTRIBUTING.md)
à la racine du dépôt. En résumé :

1. Clone le dépôt et lance un serveur statique local (`python3 -m http.server`).
2. Les défis sont définis dans
   [`js/data.js`](https://github.com/BloopStudio/htmlgame/blob/main/js/data.js).
3. Teste ton changement dans le navigateur.
4. Ouvre une pull request en décrivant ce que tu as changé.

Merci de respecter le
[Code de conduite](https://github.com/BloopStudio/htmlgame/blob/main/CODE_OF_CONDUCT.md)
du projet.
